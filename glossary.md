# Глоссарий

| Термин | Значение |
|---|---|
| FP | Функциональная точка, единица функционального размера системы. |
| KLOC | Тысяча строк исходного кода. |
| SF | Коэффициент масштаба COCOMO II. |
| EM | Множитель трудоёмкости. |
| Effort | Трудоёмкость в человеко-месяцах. |
| TDEV | Расчётная календарная длительность разработки. |
| Накладные расходы | Расходы сверх прямого фонда оплаты труда. |
| COCOMO II | Параметрическая модель оценки трудоёмкости и стоимости разработки ПО. |
